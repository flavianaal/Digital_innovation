# 📚 Digital Innovation

Repositório criado para reunir atividades, exercícios e práticas desenvolvidas durante meus estudos de programação.

## 💡 Sobre o projeto

Este repositório contém diferentes exercícios utilizados para praticar conceitos fundamentais de programação, organização de código e desenvolvimento em JavaScript.

As atividades estão organizadas em diferentes pastas, de acordo com os conteúdos e exercícios estudados.

## 📂 Conteúdo

O repositório contém atividades relacionadas a:

* `Funcoes` — exercícios envolvendo funções
* `arrayList` — prática com listas e estruturas de dados
* `aula1` — exercícios iniciais
* `classeseobjetos` — prática com classes e objetos
* `exercicio2` — exercício de programação
* `exercicio3` — exercício de programação
* `importacao` — prática relacionada à importação de arquivos
* `praticando` — exercícios de prática
* `teste.js` — arquivo utilizado para testes

## 🛠️ Tecnologias

* JavaScript
* Git
* GitHub

## 🎯 Objetivo

Praticar fundamentos de programação e JavaScript por meio de exercícios desenvolvidos durante os estudos, explorando diferentes conceitos e formas de organização do código.
